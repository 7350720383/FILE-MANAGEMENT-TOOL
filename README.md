# FILE-MANAGEMENT-TOOL
### **C++ File Management Tool - Description**  

#### **📌 Overview**  
The **C++ File Management Tool** is a simple command-line application that allows users to manage text files by writing, appending, and reading data. It demonstrates essential file handling operations in C++ using `fstream`, `ofstream`, and `ifstream`.  

#### **🔹 Features**  
1. **Write to File** – Overwrites the existing content in `data.txt`.  
2. **Append to File** – Adds new data without deleting previous content.  
3. **Read from File** – Displays the contents of `data.txt`.  
4. **Exit** – Closes the program.  

#### **🔧 How It Works**  
- Users select an option from a menu.  
- The program performs the chosen operation on `data.txt`, creating it if it doesn’t exist.  
- It uses C++ file streams to handle file input and output efficiently.  

#### **🛠️ Use Cases**  
- Learning **file handling** in C++.  
- Implementing basic **text file operations**.  
- Creating a simple **logging tool**.  

#### **💻 Technologies Used**  
- **Language**: C++  
- **Compiler**: g++ (MinGW for Windows)  

#### **🚀 Future Enhancements**  
- Adding **error handling** for file operations.  
- Implementing a **delete file** option.  
- Improving user interaction with a **better UI**.
